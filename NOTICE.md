## What This Fork Changes

This fork strips the UI down to local APK import and launching. It removes:

- Google login and Google Play API integration
- in-app APK downloading
- profile management
- update checking
- archival version list UI
- mod manager UI
- troubleshooter UI
- webview/login helper UI
